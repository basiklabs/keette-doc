This tab is the **API reference** — endpoint playgrounds generated from [`openapi.yaml`](/openapi.yaml), not narrative guides.

Authenticate with `Authorization: Bearer sk_live_…` or `sk_test_…`. See [Authentication](/auth/overview) and [Environments](/environments) in Guides.

Playground default base URL:

```text
https://api.keette.com/v1
```

Live vs sandbox is selected by your API key, not by a separate host.

## Suggested order

- **Money movement:** Utilities (`scheme` / banks) → Beneficiaries → Payouts.
- **Commerce:** [Commerce guide](/guides/commerce) → Products → Customers → Checkout → [webhooks](/webhooks/events#commerce).
