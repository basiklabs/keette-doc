Keette Developers is the home for the public HTTP API. Integrate payouts, collections, swaps, beneficiaries, and signed webhooks into your product.

One base URL. Live or sandbox is chosen by your API key — not by a separate host.

<Tip>
  **Guides** explain concepts. **API reference** is the interactive OpenAPI playground for real endpoints ([Mintlify API docs model](https://www.mintlify.com/docs)).
</Tip>
