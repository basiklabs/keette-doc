Event type names are a **stable contract**. Once shipped, a type is never renamed or removed — only new types are added. Naming follows `event.<resource>` or `event.<resource>.<action>`.

Subscribe only to what you need per webhook endpoint. Each delivery body is:

```json
{
  "id": "…",
  "object": "event",
  "type": "event.payout.completed",
  "created": 1730000000,
  "livemode": false,
  "environment": "sandbox",
  "data": { }
}
```

`data` is always the **last** key. Money values in `data` are JSON **floats** in major units with **6 decimal places** (`0.310000`). Companion `*_minor` fields are Ledger integers (`31` when `scale` is `2`).

The same catalog appears under **Settings → Developers → Webhooks**.

## Account

| Type | When |
| ---- | ---- |
| `event.ping` | Dashboard test or `POST /v1/ping` |
| `event.api_key.created` | An API key was created in this environment |
| `event.api_key.revoked` | An API key was revoked |

## Beneficiaries

| Type | When |
| ---- | ---- |
| `event.beneficiary.created` | Recipient created |
| `event.beneficiary.updated` | Recipient updated |
| `event.beneficiary.archived` | Recipient archived |

`data` mirrors the public beneficiary object (`kind`, address, `routing`, `scheme`, `route_label`, …) plus `business_id`.

## Payouts

| Type | When |
| ---- | ---- |
| `event.payout.created` | Payout created (or awaiting approval) |
| `event.payout.processing` | Held and queued / sending |
| `event.payout.cancelled` | Cancelled before the send left Keette |
| `event.payout.completed` | Send completed successfully |
| `event.payout.failed` | Send failed |

## Swaps

| Type | When |
| ---- | ---- |
| `event.swap.created` | Book-to-book FX transfer started |
| `event.swap.completed` | Swap completed |
| `event.swap.failed` | Swap failed |

`data` includes both legs as floats (`amount_from` / `amount_to`) plus `*_minor`, `fx_rate` / `rate`, `fees`, `rail` / `channel` (`internal`), and a short `timeline`.

## Payins

| Type | When |
| ---- | ---- |
| `event.payin.created` | Deposit intent or funding attempt started |
| `event.payin.completed` | Deposit credited your balance |
| `event.payin.failed` | Deposit failed or expired |

Created events carry method/channel and float amounts. Completed events add `gross` / `fee` / `net` (and `*_minor`), `rail`, optional `sender` details, `fees`, and `timeline`.
