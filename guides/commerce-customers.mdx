Payer records you bill. Create a customer, then attach a product (or create a subscription / invoice) to open billing.

```bash
# Create customer
curl https://api.keette.com/v1/customers \
  -H "Authorization: Bearer sk_test_…" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Ada Okoye",
    "email": "ada@example.com",
    "country": "NG",
    "address": {
      "line_1": "12 Admiralty Way",
      "city": "Lagos",
      "country": "NG"
    }
  }'

# Attach a product (one-time → invoice; recurring → subscription + invoice)
curl https://api.keette.com/v1/customers/{customer_id}/products/{product_id} \
  -X POST \
  -H "Authorization: Bearer sk_test_…" \
  -H "Content-Type: application/json" \
  -d '{}'
```

### Which endpoint?

| Goal | Product kind | Endpoint |
| ---- | ------------ | -------- |
| Attach + invoice | `one_time` or `recurring` | `POST /v1/customers/{id}/products/{product_id}` |
| Subscription only API | `recurring` | `POST /v1/customers/{id}/subscriptions` |
| Invoice only (no attach) | `one_time` | `POST /v1/customers/{id}/invoices` |

Do **not** call `/subscriptions` with a one-time product — that returns `parameter_invalid`. See [Billing](/guides/commerce-billing).

| Method | Path |
| ------ | ---- |
| `GET` | `/v1/customers` |
| `POST` | `/v1/customers` |
| `GET` | `/v1/customers/{id}` |
| `PATCH` | `/v1/customers/{id}` |
| `POST` | `/v1/customers/{id}/archive` |
| `POST` | `/v1/customers/{id}/products/{product_id}` |
| `DELETE` | `/v1/customers/{id}/products/{product_id}` |

Attach responses use `object: "commerce_attach_result"` with `attachment` and optional `subscription` / `invoice`.
