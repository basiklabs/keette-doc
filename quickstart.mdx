Get from zero to a successful authenticated call.

## Prerequisites

- A **business** Keette workspace with Developers access enabled
- Permission to manage API keys (admin or developer role)
- `curl` or any HTTP client

Individual accounts stay on live dashboard mode only and do not issue sandbox keys.

## Get started

<Steps>
  <Step title="Create an API key">
    In the dashboard go to **Settings → Developers → API keys**. Create a **test** key (`sk_test_…`) with an expiry of at most 90 days. Copy the secret once — it is not shown again.
  </Step>
  <Step title="Call the API">
    Use the same base URL for live and test. The key selects the environment.

    ```bash
    curl https://api.keette.com/v1/me \
      -H "Authorization: Bearer sk_test_…"
    ```

  </Step>
  <Step title="Check the environment">
    The response includes which environment the key unlocked (`live` or `sandbox`). Objects created with a test key never appear under a live key.
  </Step>
</Steps>
