# Keette Developers

Public API documentation for Keette, built with [Mintlify](https://mintlify.com).

## Local preview

```bash
npm i -g mint
cd keette-doc
mint dev
```

Open [http://localhost:3000](http://localhost:3000).

## Brand

- Colors: primary `#061F00`, accent `#A5E119`
- Font: Uncut Sans (`fonts/UncutSans-Variable.woff2`)
- Logo: Keette wordmark + **Developers** (`logo/light.svg`, `logo/dark.svg`)

## Writing

After each public API / webhook / security slice ships, update the matching pages under `api-reference/` or `webhooks/` in the same change set. See `AGENTS.md`.
